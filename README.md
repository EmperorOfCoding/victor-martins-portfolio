# 🚀 Portfolio Victor Martins

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido para demonstrar minhas habilidades como Engenheiro de Software Full Stack, com foco em experiência do usuário (UX), design moderno e performance.

![Portfolio Preview](/public/image.png)

## 🌟 Funcionalidades

*   **Design Híbrido & Moderno:** Layout que combina Bento Grid para projetos e Timeline vertical para jornada/educação.
*   **Internacionalização (i18n):** Suporte completo para Português (PT), Inglês (EN) e Espanhol (ES).
*   **Modais Expandidos:** Visualização detalhada de projetos sem sair da página, com suporte a vídeos, abas de informações e galerias.
*   **Feedback Sonoro (UI Sounds):** Efeitos sonoros sutis em interações (clique, hover) para uma experiência mais tátil.
*   **Animações Suaves:** Transições fluidas utilizando `framer-motion` e micro-interações.
*   **Download Inteligente de Currículo:** Entrega automática do currículo em Inglês ou Português dependendo do idioma selecionado.
*   **Totalmente Responsivo:** Adaptado perfeitamente para Mobile, Tablet e Desktop.
*   **Dark Mode Nativo:** Interface desenhada com glassmorphism e cores vibrantes em fundo escuro.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído com as tecnologias mais recentes do ecossistema React:

*   **Core:** [Next.js 15](https://nextjs.org/) (App Router), [React 19](https://react.dev/)
*   **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
*   **Estilização:** [Tailwind CSS v4](https://tailwindcss.com/)
*   **Animações:** [Framer Motion](https://www.framer.com/motion/)
*   **Internacionalização:** [next-intl](https://next-intl-docs.vercel.app/)
*   **Ícones:** [Lucide React](https://lucide.dev/)
*   **UI Components:** [Radix UI](https://www.radix-ui.com/) (primitivos acessíveis)
*   **Sons:** [use-sound](https://github.com/joshwcomeau/use-sound)

## 🚀 Como Executar

Siga os passos abaixo para rodar o projeto localmente:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/EmperorOfCoding/victor-martins-portfolio.git
    cd victor-martins-portfolio
    ```

2.  **Instale as dependências:**
    ```bash
    npm install
    # ou
    yarn install
    # ou
    pnpm install
    ```

3.  **Rode o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```

4.  **Acesse:**
    Abra [http://localhost:3000](http://localhost:3000) no seu navegador.

## 📂 Estrutura do Projeto

*   `app/[locale]`: Páginas e rotas do Next.js (com suporte a i18n).
*   `components`: Componentes React reutilizáveis (Hero, Modais, Cards, etc.).
*   `contexts`: Gerenciamento de estado global (Context API).
*   `messages`: Arquivos de tradução JSON (en, pt, es).
*   `public`: Assets estáticos (imagens, vídeos, documentos).
